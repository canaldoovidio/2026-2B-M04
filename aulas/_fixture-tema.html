Código e explicação

O trecho ao lado carrega os dados e treina um modelo simples de classificação.

import pandas as pd
from sklearn.linear_model import LogisticRegression

dados = pd.read_csv("dados.csv")
X = dados.drop(columns=["alvo"])
y = dados["alvo"]

modelo = LogisticRegression()
modelo.fit(X, y)
