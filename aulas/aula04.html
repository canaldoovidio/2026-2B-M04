Endereço, ponteiro e conteúdo

A memória é uma fileira de armários numerados. O número do armário é o endereço; um papel com esse número anotado é o ponteiro; abrir o armário e olhar dentro é o conteúdo.

Dois ponteiros dividem um vetor de 8 posições

Pense num bloco de 8 recados preso num anel: quem anota escreve na próxima folha livre, quem lê pega a folha mais antiga, e os dois voltam à primeira folha depois da oitava.

PonteiroAponta paraAnda quandoDepois de buffer[7]
escritaa próxima posição livreum evento é guardadovolta para buffer[0]
leiturao evento mais antigo ainda não enviadoa conexão envia um eventovolta para buffer[0]

Com os dois ponteiros na mesma posição, o buffer pode estar vazio ou cheio; o contador guardados desfaz a dúvida. Ocupação: 8 posições × 8 bytes de cada Evento = 64 bytes.

10

Uma comparação faz o ponteiro dar a volta

Evento *avancar(Evento *p) {
  p++;                       // anda sizeof(Evento) bytes
  if (p == buffer + CAPACIDADE) {
    p = buffer;              // passou do fim: volta
  }
  return p;
}

void guardar(unsigned long agora) {
  // (buffer cheio: aplica a política)
  escrita->sequencia = proximaSequencia++;
  escrita->instanteMs = agora;
  escrita = avancar(escrita);
  guardados++;
}

buffer + CAPACIDADE é o endereço logo depois da última posição. Quando o ponteiro chega ali, ele volta para buffer, que é o endereço de buffer[0].

escrita->sequencia é o mesmo que (*escrita).sequencia: o campo do evento para onde o ponteiro aponta.
