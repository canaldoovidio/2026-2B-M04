O switch recusa 12 das 16 combinações

enum class Estado { Cadastrado, EmTransito,
                    NoFornecedor, Retornado };
bool transicao(Estado atual, Evento evento,
               Estado &proximo) {
  switch (atual) {
    case Estado::Cadastrado:
      if (evento == Evento::Saida) {
        proximo = Estado::EmTransito;
        return true;
      }
      break;        // sem ele, cai no caso seguinte
    // os outros 3 casos seguem o mesmo molde
  }
  return false;     // as outras 12 combinações
}

São 4 estados × 4 eventos (Saida, Chegada, Retorno, Liberacao) = 16 combinações. Quatro avançam o ciclo; as outras 12 caem no return false e o estado não muda.

enum class dá nome aos números: Estado::Retornado no lugar de um 3 solto, e o compilador recusa comparar um estado com um evento.

Laboratório em dupla no Wokwi: ESP32

  1. Abra o laboratório da Aula 03 num projeto ESP32 novo do Wokwi e cole o circuito e o código.
  2. Leia no monitor serial os três ciclos abertos e compare com a previsão da dupla.
  3. No ciclo ao vivo, aperte retorno antes de saída e confira que o estado não muda.
  4. Faça saída e chegada. Com 1 dia simulado a cada 100 ms, o LED de atraso acende 3,1 s depois da saída e o de permanência 15,1 s depois, em tempo simulado: leia no relógio da barra da simulação do Wokwi ou pelos instantes em ms que a serial imprime, porque a simulação pode rodar mais devagar que o relógio de parede.
  5. Anote no PROCESSO.md o que você previu e o que observou.

Confronto com a IA: a transição proibida

  1. Peça ao Gemini uma máquina de estados para o ciclo, com os mesmos quatro estados e quatro eventos.
  2. Em dupla, aplique ao código da IA as cinco combinações proibidas da tabela do laboratório, etapa Confrontar.

  5. Uma sugestão rejeitada ou corrigida vira o ADR do aluno.
